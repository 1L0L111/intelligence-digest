# Submission checklist

- [ ] Каждый участник авторизован в GitLab через Codenrock.
- [ ] Feature branch -> Merge Request -> main (прямой push в main запрещён).
- [ ] В main лежит актуальный код, README, зависимости, sample data, tests.
- [ ] `pytest -q` проходит локально.
- [ ] `streamlit run frontend/app.py` стартует без API-ключа.
- [ ] Переключение Security Engineer -> CIO меняет подборку.
- [ ] Markdown и DOCX скачиваются.
- [ ] Источники сохранены у каждого события.
- [ ] `submission/presentation.pdf` загружен на Codenrock (до 20 MB).
- [ ] На защите не заявлять непроверенные production-метрики.
